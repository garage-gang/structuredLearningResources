Battleship!

This is a simple version of one-player battleship. You play
the game until you win!

There are 5 files:
- src/Battleship.java
- src/BattleshipTests.java
- src/Game.java
- src/MoveResult.java
- src/Ship.java
- src/ShipPlacement.java

There are a few to-do's for you in `src/Battleship.java`.
- It is the only file that you should have to modify.
You can check your work by running `src/BattleshipTests.java`.
- If all the tests pass, then you've succeeded!

Although you do not have to modify the other files, I suggest
looking at all of them before starting!

Happy coding!
